# 런타임 선택

## 기본은 Node.js

특별한 이유가 없다면 모든 새 라우트/페이지는 Node.js 런타임을 쓴다.

```tsx
export default function Page() { /* ... */ }
// 별도 runtime 설정 불필요
```

## Edge는 필요할 때만

"이미 Edge를 쓰고 있거나, 구체적인 이유가 있을 때만" Edge 런타임을 쓴다.

```tsx
export const runtime = 'edge'
// 프로젝트가 이미 Edge를 쓰고 있거나 특정 요구사항이 있을 때만 추가
```

## 선택 기준

**Node.js가 필요한 경우**: 전체 Node.js API, `fs` 파일시스템, 폭넓은 암호화 지원, DB 연결, 대부분의 npm 패키지 호환성

**Edge가 적합한 경우**: 지리적 분산이 필요, 명확한 지연시간 요구사항, 콜드스타트를 줄여야 하는 상황, 이미 Edge 아키텍처를 쓰는 프로젝트

## 결정 전 체크리스트

- 이미 Edge를 쓰고 있는가?
- 구체적인 지연시간 요구사항이 문서화돼 있는가?
- 의존하는 패키지가 모두 Edge의 제한된 환경에서 동작하는가?

확신이 없으면 Node.js를 유지한다.
